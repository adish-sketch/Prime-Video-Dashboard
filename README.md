# Prime-Video-Dashboard

 Prime Video Content Analysis Dashboard

An interactive Power BI dashboard designed to analyze the Prime Video
content library, including movies, TV shows, genres, ratings,
directors, and yearly release trends.

#Dashboard Preview

---

##  Project Overview

The Prime Video Content Analysis Dashboard provides a visual overview
of the available content library.

The dashboard helps analyze:

- Movies vs TV Shows
- Content ratings
- Genres
- Top directors by number of titles
- Content released over the years
- Total titles
- Total movies
- Total TV shows
- Total directors


# Objectives

- Analyze the distribution of Movies and TV Shows
- Identify the most common genres
- Analyze content ratings
- Identify directors with the highest number of titles
- Understand content release trends over the years
- Build an interactive and visually appealing Power BI dashboard

# Tools & Technologies

- Power BI
- Microsoft Excel
- Data Cleaning
- Data Visualization
- Dashboard Design
- DAX
- Power Query
